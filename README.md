# QuickCart Stockout Risk Prediction

QuickCart Stockout Risk Prediction is a Machine Learning classification project designed to identify the risk of inventory stockouts at different stores.

The project combines inventory, product, store, supplier, and event data to predict whether a product is:

🟢 Safe – Sufficient inventory available  
🟡 At-Risk – Inventory is approaching the replenishment limit  
🔴 Imminent – Higher risk of stockout before replenishment

## 📈 Machine Learning Model

The project uses a Random Forest Classifier to classify inventory records into three stockout-risk categories:

- Safe
- At-Risk
- Imminent

Model evaluation includes:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Feature Importance
